# 结果码与语言资源

业务响应固定为 {code,data,message}。code 为八位数字：2 开头成功，1 开头失败；HTTP 状态独立映射。message 只提供开发诊断，用户提示从语言字典读取。

```ts
format(data, RESPONSE_CODES.SUCCESS)
format(data, RESPONSE_CODES.CREATED)
throw new ResponseCodeError(RESPONSE_CODES.INVALID_INPUT)
```

GET /api/i18n/zh-CN 与 /api/i18n/en-US 公开返回统一响应包装的嵌套字典；命名空间默认 server。两份语言叶子 key 必须与结果码注册表完全一致。新增结果码时同步中英文资源与 HTTP 映射，运行 i18n 回归验证。
