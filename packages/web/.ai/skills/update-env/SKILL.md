# 修改环境变量

当需要新增或修改 app 环境变量时使用这个技能。

## 流程

1. 读取 `AGENTS.md`。
2. 读取 `80-env-and-config.md` 和 `86-documentation-sync.md`。
3. 判断是否已有可复用环境变量。
4. 修改公共默认配置时更新 `env/.env`。
5. 新增或修改变量时同步 `env/.env.example`。
6. 添加注释说明变量作用。
7. 私有值放到 `.local`，不要写入公共配置。
8. 配置读取集中在配置或接入边界。
9. 按 `86-documentation-sync.md` 判断是否需要同步文档。
10. 按 `90-quality-gates.md` 运行最小必要验证。

## 规则

- 不重复定义同一语义的环境变量。
- 不在业务代码中散落读取环境变量。
- 缺失配置是否兜底取决于配置契约。
