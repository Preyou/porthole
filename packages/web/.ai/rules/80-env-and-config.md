# Env And Config

环境变量位于 `env` 目录。

## 当前文件

- `env/.env`：公共默认配置，可以提交。
- `env/.env.example`：环境变量示例。
- `env/.env.*.local`：本地或私有覆盖配置，不应提交。

## 规则

- 新增环境变量时，同步更新 `env/.env.example`。
- 新增环境变量时，添加合适注释说明用途。
- `env/.env.example` 中每个环境变量都必须有相邻中文注释说明用途；没有中文注释不算完成 example 同步。
- 可复用的环境变量应当复用，不为同一语义新增重复变量。
- 私有配置放到 `.local`，不要写入公共配置文件。
- 配置读取应集中在配置或接入边界，不要在业务代码中散落读取环境变量。
- 缺失配置是否兜底取决于配置契约，不随手写默认值。
