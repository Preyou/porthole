# I18n And Copy

app 层承载产品文案和业务文案。

## 规则

- app 文案放在 `src/locales`。
- 新增页面、按钮、提示、状态文案时，同步更新 app locale。
- 应用可以覆盖任意 `ui.*` 文案。
- 不把产品文案写进 `@ngt/ui`。
- 组件内部不需要硬编码 fallback；应通过 app locale 或 props/slots 提供展示内容。

## 界面文案硬约束

- **任何时候都不得把开发状态作为文案渲染到界面上**。原型、演示、开发、测试、评审、内部使用与正式发布均不构成例外。
- 禁止展示关于当前实现的研发进度、开发阶段、完成情况、实现来源、技术方案或验证方式，例如“开发中”“尚未接入接口”“暂用 Mock 数据”“仅完成前端”“待联调”“占位实现”。不得通过标题、徽标、正文、按钮、空状态、提示、通知、示例数据或其他界面载体间接表达这些信息。
- 开发者写给 agent 的需求描述、实现要求和约束说明同样不得直接作为界面文案；应落实为控件、校验、状态、交互或数据处理。
- 界面只表达用户需要理解、选择或处理的产品语义、业务状态和数据。加载、保存、失败等真实业务运行状态按产品语义表达，不混入研发说明。
- 研发状态只记录在代码注释、测试、开发日志、任务记录或开发文档中，不因本地运行、使用固定数据或功能尚未完成而渲染到界面。

## 当前结构

- `src/locales/zh-CN.json`
- `src/locales/en-US.json`
- `src/locales/index.ts`

## 注意事项

- 新增 locale key 时保持命名语义清晰。
- 删除或重命名 key 前，检查页面引用。
- 模板 app 不写具体产品业务文案；复制后的业务 app 可以写具体产品文案。
